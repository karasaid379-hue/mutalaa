# İnsan adımları

> **Sürüm:** 1.10 · **Tarih:** 11 Kasım 2026 · **Durum:** Canlı belge
> **Bağlı kararlar:** [K-42](../00-ozet/02-karar-defteri.md#k-42--kaynak-ilkesi-ve-kalite-temelli-görünürlük) · [K-31](../00-ozet/02-karar-defteri.md#k-31--geliştirme-aracı-claude-code) · [K-38](../00-ozet/02-karar-defteri.md#k-38--kaynak-edinimi-dijital-öncelikli-kanıtla-yükseltme) · [K-49](../00-ozet/02-karar-defteri.md#k-49--elmalılı-mealleri-hazır-metin-yolu-ve-ocrın-proje-sonuna-ertelenmesi)

İnsan adımı yalnız hesap, altyapı, ödeme ve editör emeğidir ([K-42](../00-ozet/02-karar-defteri.md#k-42--kaynak-ilkesi-ve-kalite-temelli-görünürlük) madde 3). Claude Code bu işleri yapamaz: hesap açma, ödeme, sistem geneli kurulum, insan editör kararı ve düzeltmesi. Claude Code hazırlığı yapar (kontrol listesi, araç, kuyruk), işi siz yaparsınız ve sonucu Claude Code'a söylersiniz; Claude Code bu dosyayı günceller. Bekleyen bir insan adımı yalnız kendisine bağlı alt adımı bekletir; aşamanın kalanı ve öteki aşamalar sürer, Claude Code devam için sormaz. İçerik kaynaklarını Claude Code kendisi indirir (aşama dosyalarının `## Tedarik` bölümü).

Durum değerleri: `bekliyor`, `sürüyor`, `tamam`, `gerekmiyor`.

## Nasıl güncellenir

- İnsan adımı gerektiren iş çıkınca Claude Code hazırlığı yapar (kontrol listesi, araç, kuyruk), adımı `bekliyor` bırakır ve yalnız o adıma bağlı alt adımı bekletir; aşamanın kalanı sürer.
- Adıma başladığınızda ya da bitirdiğinizde Claude Code'a söyleyin ("İ-23 sürüyor", "İ-23 tamam, tarih …"): durum `sürüyor` ya da `tamam` olur; tarih ve kısa not yazılır.
- Adım gerekmiyorsa durum `gerekmiyor` olur ve gerekçesi yazılır; koşul sonradan gerçekleşirse `bekliyor` olur (ör. İ-09).
- İlerleme dosyasının durum bloğundaki "Bekleyen insan adımları" satırı buna göre güncellenir.
